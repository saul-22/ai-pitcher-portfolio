# 产品定位与价值逻辑

> 脱敏重写版。完整定稿含定价论证与销售动线，此处保留可公开的方法层。

## 一句话定位

**AI 智能投手：7×24 替商家操盘千川投放的执行 Agent。优化师当指挥官、定策略；它干盯盘、止损、调价的累活，让一个优化师管出一个团队的盘。**

铁律：**赋能优化师，不替代优化师。** 禁止"省 N 个人 / 1 个 AI = N 个投手"的人头除法——页面永远只讲优化师个人获得（管更多、不熬夜），老板自己会算扩张账。

## 双受众，同一产品

| 受众 | 要什么 | 怎么满足 |
|---|---|---|
| 老板 / 运营总监 | 整盘健康、值不值、敢不敢放权 | 店铺/跨账号作用域、成果页、权限审计视图 |
| 优化师 | 我的盘被接住、我变强、我可控 | 账号作用域、拍板收件箱、调整后执行、计划档案可核验 |

切换靠作用域选择器（店铺 → 账户），不做两套界面。

## 两道锁（所有价值表述的前提）

1. **钱证不了**：增收/省钱是反事实（大促、货品、行情都在变），敢报钱数就会被"怎么证明是你不是大促"戳穿，戳穿一处全页信任塌。
2. **不能得罪优化师**：用的人是优化师，替代叙事 = 抵制 = 推不动。

## 能讲清 / 讲不清的线

**能讲（全是可核验事实）：** 在岗与覆盖（7×24 / N 条 / 秒级响应 / 夜间）、实际动作（次数 + 每次前后状态）、风险兜底（暂停了 X 条持续亏损的计划，可逐条回看）、动作质量（误杀率 / 撤回率 / 守线率，有观察窗口）、克制（N 次巡检判断无需动作）。

**不讲（反事实 / 证不了）：** 帮你赚/省 ¥X；单计划"不调会怎样"；把整体经营算成功劳；把消耗切成放量/止损贡献占比。

**文案口径：** 聚合层说「持续亏损」（业务语言），不说"跌破盈亏线"（术语）；术语只出现在弹窗、规则等需要精确的细节处。

## 高价靠什么

定价锚定人力成本的一个分数（一个 7×24、数百条计划同时盯、秒级出手的"投手"），面向月消耗达到一定门槛的商家——年费占其广告消耗比例足够小，决策轻。

三根可观测的柱子，都不需要反事实：

1. **产能**：管的计划/账户数直接数得出
2. **在岗覆盖**：7×24 / 夜间 / 秒级，人力物理做不到
3. **风险兜底**：保险逻辑，按"覆盖"定价，不按"证明省了多少"

**"提升"的证明有严格边界：** 试用期前后对比（各 N 天日均、标注口径、满期自动收起）是销售钩子而非常驻承诺；受控留样对照是唯一能碰因果的方法，但只在"账户够大 + 事前随机留样"的窄口成立，定位为签约期一次性背书。

## 鲁棒性

头条永远不用"比上月"。行情差时：达标率、在岗、兜底、可核验照常成立——下行期止损价值反而最大。

## 数据口径纪律

- 明细保留有限天数；窗口累计标"近 N 天"；历史累计计数器只存总量并标"累计"。
- 所有比率指标必须有观察窗口定义。
- 经营指标（GMV、投产比）只表达"当前经营表现"，不写成产品功劳。
