# 设计系统

> Token 唯一来源 = 原型页面的真实 CSS 变量。

## 品牌色

品牌蓝 `#4578be`（主）/ `#5b91d4`（次高亮），11 级色阶（primary-900 → primary-0）。

**颜色纪律：品牌蓝只用于导航激活、链接、数据图形、Agent 元素、主操作。白底 + 发丝线做结构，不大片铺蓝。**

## 中性色与结构

| 类别 | Token | 值 | 用途 |
|---|---|---|---|
| 墨色 | `--ink` | `#0f172a` | 标题 / 主文字 / 表格数值 |
| | `--ink-2` | `#475569` | 二级文字 |
| | `--ink-3` | `#94a3b8` | 标签 / 占位 / 时间戳 |
| 发丝线 | `--hair` | `#e2e8f0` | 主分割线 / 表格行线 |

| `--primary-600` | `#4578be` | 调投产比 / 采纳标 |

## 字体

- 正文：系统中文栈（PingFang SC / Microsoft YaHei）
- 数字：`Manrope` + `tabular-nums`（防跳动），**所有数字无例外**
- 时间戳 / 代号 / 计划 ID：`IBM Plex Mono`

## 布局语法

- 版心 1280px 居中；页顶留 96px 给玻璃导航；内容从玻璃下穿过（滚动时真实模糊）。
- 三岛玻璃导航：身份岛（orb 流光环 + 轮换状态）+ 导航岛（6 tab，激活 = 蓝渐变药丸）+ 上下文岛（作用域选择器）。
- **容器只有两种**：总览 = 表/卡片流；详情/配置 = 右侧抽屉（`top:84px` 避开导航）或居中弹窗。不另造第三种。
- 圆角 4/6/10px 三档；间距 4 的倍数；动效 150/200/300ms，尊重 `prefers-reduced-motion`。

## 按钮分级（权重与后果成正比）

| 级 | 用途 | 样式 |
|---|---|---|
| 主操作 | 提交/生效（保存、采纳并生效） | 蓝渐变 34–36px |
| 次操作 | 打开/取消 | ghost 描边 |
| 表格工具 | 批量填/应用 | 26px 小件，hover 才亮 |
| 行内导航 | 进详情（看档案→） | 文字链，**不是按钮** |
| 状态信息 | 规则摘要（已设态） | 纯文本 + ✎，**绝不做成按钮** |

**"可点 ≠ 按钮"是根原则**：按钮样式只给真正的操作召唤。违例（状态信息做成大按钮、批量工具用标准按钮）在评审中逐一清除。

## 表格规范

- **表格卡容器**：1px 实边框 + 13px 圆角 + 微投影，禁止裸表。
- 表头浅灰底 + 11px 小字字距；行线 = 发丝线；尾行无下线；行 hover 浅蓝。
- 数字列一律右对齐（tabular-nums），文本列左对齐，不用居中。
- **行内编辑 ≤1 个控件**：每行只允许一个高频输入（如盈亏线），其余编辑进抽屉——表格管扫读，不冒充表单。
- 底部分页必备：计数 + 每页条数 + 页码。

## 选中态二分

全局导航选中 = 品牌蓝药丸；页内筛选选中 = 墨黑药丸。二者不得混用——用户凭颜色即可区分"我在哪"和"我筛了什么"。
