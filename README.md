## 这个项目解决什么问题

电商商家在巨量千川上投放广告，优化师每天要人工盯几十上百条计划：夜间没人值守、止损靠手速、放量靠经验、每小时都可能错过窗口。平台自身的推荐机制天然倾向让商家多消耗，商家缺一个"站在自己这边"的执行者。

**AI 智能投手 = 优化师的执行外挂。** 优化师当指挥官、定策略（盈亏线、止损规则、授权范围）；Agent 干盯盘、止损、调价、追投的累活，7×24 在岗、秒级响应、每一步可核验可撤回。

## 我的角色

AI 产品经理，独立负责：

- **产品定义**：定位、价值逻辑、双受众（老板/优化师）叙事、商业化机制
- **Agent 机制设计**：L1/L2 分级授权、推荐批次时效、拍板三出口、动作记录三态标签
- **策略产品化**：把生产策略引擎的判定逻辑翻译成用户可理解、可信任的前台呈现
- **交互与原型**：六页信息架构、设计系统、可点击 HTML 原型（本仓库 Demo）
- **跨职能对接**：为后端重构输出行为规格，为销售输出价值材料

## 三个关键产品判断

**1. 赋能优化师，不替代优化师。** 用产品的人是优化师，替代叙事 = 抵制 = 推不动。全产品禁止"省 N 个人 / 1 个 AI = N 个投手"的人头除法，只讲"优化师个人获得"（管更多、不熬夜）。

**2. 钱证不了，就不要证。** "帮你赚了 ¥X" 是反事实（大促、货品、行情都在变），敢报钱数就会被一句"怎么证明是你不是 618"戳穿，戳穿一处全页信任塌。产品只证明可核验事实：托管覆盖、实际动作、夜间兜底、动作稳定性——每一条都能点开逐条核验。

**3. 信任是设计出来的，不是宣传出来的。** 推荐本批未处理自动失效（请示有时效）；删除素材默认需人工拍板；动作记录区分"我自动 / 采纳 / 调整后采纳"；Agent 允许认错（"未能止住下滑"）和认输（"你的判断对"）。克制本身就是卖点——"巡检后判断无需动作 N 次"单独展示。

## Agent 决策闭环

```
优化师立规矩（盈亏线 / 止损规则 / L1、L2 授权）
        ↓
每小时巡检全部计划与素材 → 分层判定（前置检查 → 计划级 → 素材级 → AI 兜底）
        ↓
L2 授权内 → 直接执行（可核验、可撤回）
L1 或高风险 → 进「智能优化」收件箱等拍板（采纳 / 调整后执行 / 这次不动）
        ↓
执行日志（动作前后对照）→ 计划档案（跨天决策史 + 后效复盘）→ 报告推送
```

动作词表全产品锁定：计划 = `暂停 / 调目标投产比 / 改预算`；素材 = `追投 / 删除`；外加 `维持现状`（体现克制，单独计数）。
